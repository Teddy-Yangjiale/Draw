# 论文示意图绘制手册

> 这是“怎么画”的处方；证据和 16 篇论文的拆解见 [`research/figure_analysis.md`](../research/figure_analysis.md)。

## 0. 先选图型

```
你要解释什么？
├─ 一条方法流水线 ────────────── 单主干 pipeline
├─ 预训练模型 + 少量可训练模块 ── 冻结/可训练双区
├─ 一个关键操作/编码/轨迹 ────── 逐步机制 / 轨迹图
├─ 系统很大，细节很多 ────────── 主图 + 放大面板
├─ 画质/多样性/定性对比 ──────── 结果网格
├─ 3D 场景/渲染/生成 ─────────── 3D/概念图
└─ 两个阶段/两种训练目标 ─────── 两阶段/双栏
```

不要把所有信息塞进一张图。超过 7 个主模块，就拆成 `(a) Overall` + `(b) Detail`，或把细节移到右侧放大面板。

## 1. 通用画布与网格

| 项目 | 双栏 | 单栏 |
|---|---|---|
| 画布 | `7.16 × 2.4–3.2 in` | `3.5 × 2.2–2.8 in` |
| 边距 | `0.12–0.20 in` | `0.08–0.12 in` |
| 主模块高 | `0.50–0.65 in` | `0.42–0.55 in` |
| 主模块宽 | `0.9–1.35 in` | `0.7–1.0 in` |
| 水平间距 | `0.15–0.25 in` | `0.10–0.15 in` |
| 字号 | 模块 9–11 pt；子标签 8–9 pt | 模块 8.5–10 pt；子标签 8 pt |
| 线宽 | 0.75–1.25 pt | 0.75–1.0 pt |

规则：

- 同一行模块**严格等高**；同一类模块**同宽**。
- 主流程放在画布垂直中心附近（y = 45–55%）。
- 所有坐标用 0.05 in 网格；`x`、`y`、`w`、`h` 尽量写成 2 位小数。
- 容器/面板的边距比内部模块大 1.5–2 倍，形成层级。
- 最后用 `fit_canvas` 去掉多余白边；双栏图用 `keep_width: true` 保持 7.16 in。

## 2. 图型 A：单主干 pipeline

**参考**：SAM、Depth Anything、VGGT、SOIT、3DGS。

```
[图片] → [模块1] → [模块2] → [虚线容器: 模块3/4 ×L] → [模块5] → [图片/输出]
                 ↘──────── skip / feedback ────────↗
```

推荐坐标（双栏，7.16 × 2.6）：

- 输入图片：`x=0.20, y=0.85, w=0.95, h=0.62`
- 模块 1：`x=1.40, y=0.90, w=1.15, h=0.58`
- 容器：`x=2.85, y=0.60, w=1.75, h=1.25`
- 容器内模块：`w=1.40, h=0.34`，上下间距 `0.08`
- 模块 5：`x=4.85, y=0.90, w=1.10, h=0.58`
- 输出图片：`x=6.15, y=0.72, w=0.72, h=0.48`
- 主箭头：`from_side=right, to_side=left`，`line_width=1.0`
- skip：`add_detour side=bottom offset=0.7`，虚线，标签在线上方

颜色：

- 输入/输出图片不描边（或 0.5 pt 浅灰）。
- 主模块 1 绿、模块 2 蓝、模块 5 橙；容器浅灰虚线。
- 只给一条最重要路径用强调色；其余用中性/同色系。

文字：

- 模块内 1–2 行，9–10 pt；第二行可以是更小的 8 pt 子标签。
- 图片下标签 8.5 pt，颜色 `5B6773`。

## 3. 图型 B：冻结 / 可训练双区

**参考**：HQ-SAM、BLIP-2、LoRA、EOV-Seg。

```
┌─ 冻结区（浅蓝/灰）──────────────┐   ┌─ 可训练区（浅橙）──────────────┐
│  [Image Encoder ❄] → [Q-Former] │ → │  [New Token] → [MLP] → [输出]  │
└─────────────────────────────────┘   └────────────────────────────────┘
```

画法：

1. 两个 `add_container` 虚线框，左右排列；标题放框上方，9 pt 加粗。
2. 冻结模块用**梯形**或矩形，浅蓝/灰；在左上角放 `❄` 或 `frozen` 小标签。
3. 可训练模块用桃色/橙色；新增模块用**黑色虚线框**标出。
4. 两区之间用一条粗一点的箭头；不要把所有内部箭头都画出来。
5. 输入/输出放真实图片/mask；右下角可加 8 pt 图例（冻结/可训练/损失）。

推荐坐标（双栏，7.16 × 2.5）：

- 左区：`x=0.2, y=0.55, w=3.3, h=1.5`
- 右区：`x=3.7, y=0.55, w=3.2, h=1.5`
- 冻结模块：`w=1.0, h=0.55`；可训练模块：`w=1.1, h=0.45`
- 区标题：`y=0.25, h=0.2`，9 pt 加粗
- 图例：`y=2.2, h=0.18`，8 pt

注意：

- 雪花/火焰 emoji 可能缺字体；优先用文字 `frozen` / `trainable` + 一个简单色块。
- 不要让冻结区的大面积浅色盖住内部模块；容器必须在底层。
- 如果只有一个小改动，用 LoRA 式极简 inset，不要硬做双区大图。

## 4. 图型 C：逐步机制图

**参考**：Instant NGP、Consistency Models。

```
(1) 输入/网格 → (2) 查表 → (3) 插值 → (4) 拼接 → (5) MLP → 输出
     小图/网格      表格       箭头/曲线      色条       节点图
```

画法：

- 4–6 个步骤，编号 `(1)…(5)` 放每步下方，9 pt；步骤之间用短箭头。
- 每一步给一个“小视觉”：网格、表格、色条、MLP 节点、图片条。
- 顶部一条浅色背景带可以统一整张图；不要每步一个彩色卡片。
- 公式作为文本放在对应步骤下方，字号 8–9 pt；复杂公式用透明图片。

推荐坐标（双栏，7.16 × 2.4）：

- 5 个步骤等宽：`w=1.25, gap=0.18`，从 `x=0.3` 开始
- 每步标题 `y=0.25`；图形 `y=0.55, h=1.2`；编号 `y=1.85`
- 箭头在步骤之间，`y=1.1`，水平

注意：

- 不要把所有步骤都画成同样的圆角矩形；用网格/表格/节点图区分“操作类型”。
- 颜色只用来区分子层级（如 level 0/1），不要每步一个新颜色。

## 5. 图型 D：主图 + 放大面板

**参考**：Grounding DINO、EOV-Seg、HQ-SAM。

```
┌──────────── 主图 55–60% ────────────┐  ┌─ 面板 A 40–45% ─┐
│ 输入 → 模块 → 模块 → 输出           │  │ 标题条 + 3–5 模块 │
│        ↘ 局部细节 ──────────────────┼──┤ 面板 B           │
└─────────────────────────────────────┘  └──────────────────┘
```

画法：

- 主图放左侧，保持一条水平轴；右侧两个面板上下排列，间距 `0.25–0.35 in`。
- 面板标题条高 `0.18–0.22 in`，用同色系深色填充/白字；面板本体浅底/细边框。
- 面板内部只放 3–5 个模块，字号可以比主图小 0.5–1 pt，但不小于 8 pt。
- 用一条细虚线/浅色引导线指向“放大来源”；不要画粗大箭头穿过主图。
- 主图可以密，但面板必须可读；如果面板也密，说明该拆图了。

推荐坐标（双栏，7.16 × 3.2）：

- 主图：`x=0.2, y=0.4, w=4.1, h=2.4`
- 面板：`x=4.55, w=2.4`；上 `y=0.4, h=1.0`；下 `y=1.55, h=1.0`
- 标题条：`h=0.2`，8.5 pt 加粗

## 6. 图型 E：结果网格 / 定性对比

**参考**：Diffusion Models Beat GANs、DreamFusion、3DGS。

```
┌────┬────┬────┬────┬────┬────┐
│    │    │    │    │    │    │   ← 图片等大、无间距
├────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │
└────┴────┴────┴────┴────┴────┘
  (a) Baseline   (b) Ours   (c) GT
```

画法：

- 3×6、4×4 或 2×4；图片等大，单元格无间距或 1–2 px。
- 图片用 `contain` 会留白，用统一裁切/`cover` 更整齐；不要手动拉伸。
- 列标签放底部或顶部，8–9 pt；不要给每张图加边框/阴影。
- 画布宽度按列数算：`7.16 in / 6 ≈ 1.19 in` 每张；高度按图片比例。
- 结果是“画质”说话，不要加装饰性模块框。

推荐坐标（双栏，7.16 × 2.4）：

- 6 列：`cell_w=1.14, gap=0.02`，从 `x=0.15` 开始
- 3 行：`cell_h=0.62, gap=0.02`
- 列标签：`y=2.05`，8.5 pt

程序：`add_image_grid`，`cols`、`cell_w/cell_h`、`gap`、`labels`。

## 7. 图型 F：轨迹 / 概念映射

**参考**：Consistency Models、LoRA。

```
[图 x0] → [图 xt] → [图 xT]      ← 图片条 + 绿色前向箭头
   ↖─────── fθ(xt,t) ───────┘    ← 红色映射回原点
```

画法：

- 顶部一条等距图片序列（4–6 张），下方一条水平箭头表示前向过程。
- 曲线/折线箭头从任意点指回起点；颜色只给“映射”这一种语义。
- 标签用数学符号，8–9 pt；公式放图下方或箭头旁。
- 背景留白，不要加模块框；这是“概念图”，不是架构图。

推荐坐标（双栏，7.16 × 2.2）：

- 图片条：`x=0.4, y=0.35, w=1.1, h=0.55`，间距 `0.08`
- 前向箭头：`y=1.05`；映射箭头：`y=1.2–1.8`
- 公式/标签：`y=1.75`，8.5 pt

## 8. 图型 G：3D / teaser

**参考**：NeRF、4DGS、DreamFusion、3DGS、Instant NGP。

画法：

- 3D 主体（场景、Gaussian、人物、兔子、孔雀）用 Blender / 论文代码 / Matplotlib 渲染，保存透明或浅底 PNG。
- PPT 只画：外层流程、箭头、编号、文字、图例。
- 可以在 3D 图上叠加半透明色块/箭头/标签，但不要用 PPT 形状重建 3D。
- 背景尽量白/浅灰；3D 渲染图边缘要和画布融合，避免黑底/硬边。
- 如果 3D 图本身信息量很大，不要再加密集模块；用一张 teaser + 一张 pipeline 分开。

## 9. 颜色 / 线型 / 字体速查

| 语义 | 建议 |
|---|---|
| 冻结/预训练 | 浅蓝 `DCEBF7` / 灰 `F2F0EC`，描边 `5B8DB8` / `B8B1A6` |
| 可训练/新增 | 桃色 `FBE7D8`，描边 `C98A62` |
| 主模块 | 蓝/绿/橙三选一，浅填充+同色描边 |
| 损失/错误 | 文字/箭头 `C05243`，不要整块大红 |
| 梯度/反传 | 青蓝 `2AA7C8`，可加粗/弯曲 |
| 可选/未标注/反馈 | 虚线 + 中性灰 |
| 容器/阶段 | `FBFCFD` + `C9D2DA` 虚线 |
| 图例/注释 | 8 pt，`5B6773` |

- 箭头：前向深灰 `4B5763` 1 pt；梯度青色 1.25 pt；虚线 0.75–1 pt。
- 字体：Arial / Helvetica；中文 Arial Unicode / Microsoft YaHei / Noto Sans CJK。
- 绝不小于 8 pt；8 pt 只用于图例/列标签。

## 10. 提交前检查清单

- [ ] 画布尺寸正好是目标栏宽（双栏 7.16 in / 单栏 3.5 in）。
- [ ] 主流程 4–7 个模块，一条水平轴；没有上下折返。
- [ ] 同一行模块等高；同类模块同色/同宽。
- [ ] 箭头端口对齐，没有穿过模块/文字；skip 走外侧。
- [ ] 模块文字 9–11 pt，图例 8 pt；没有溢出（`pptdraw lint`）。
- [ ] 颜色 ≤3 主色 + 1 强调色；同语义同色；必要时有图例。
- [ ] 输入/输出用真实图片；3D 用渲染图导入，不是 PPT 硬画。
- [ ] 图内没有标题/图注；面板编号只有 `(a)(b)`。
- [ ] 白底、无阴影/渐变/3D 立体框。
- [ ] 导出 PDF 后在 100% 和 50% 缩放下都能读。

## 11. 图型 → ops 对照

| 要做的事 | ops |
|---|---|
| 放输入/输出图片 | `add_picture` / `add_image_grid` |
| 主模块 | `add_shape`（`roundRect`/`rect`） |
| 冻结编码器 | `add_shape`（`trapezoid`）+ `frozen` 标签 |
| 特征金字塔 | `add_shape`（`parallelogram`）+ 多个堆叠 |
| 阶段/重复容器 | `add_container`（`style: container`） |
| 主流程箭头 | `add_connector`（`from`/`to` 用形状名） |
| skip/feedback | `add_detour`（`side: bottom/top`） |
| 复杂绕线 | `add_route`（自由折线，不挂接） |
| 对齐/等距 | `align` / `distribute` / `layout_row` / `layout_column` |
| 裁白边 | `fit_canvas`（`keep_width` 可选） |
| 组件层级 | `normalize_z` |

完整字段见 [`docs/ops.md`](ops.md)。
